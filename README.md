# Banking Chatbot

## Project Overview
The Banking Chatbot is a Python-based application designed to answer banking-related questions using public banking documents and Large Language Models (LLMs).

## Objectives
- Understand and answer banking-related queries.
- Collect public banking documents.
- Process and organize banking information.
- Integrate an LLM API.
- Generate relevant answers to user questions.

## Technologies
- Python
- Git and GitHub
- Large Language Models (LLMs)
- Natural Language Processing (NLP)

## Project Structure
- `documents/` - Banking-related documents
- `src/` - Python source code
- `data/` - Project data
- `README.md` - Project documentation
- `requirements.txt` - Project dependencies

## Project Status
Currently in the initial development stage.
