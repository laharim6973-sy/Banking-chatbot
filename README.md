
# Banking Chatbot

## Project Overview
The Banking Chatbot is a Python-based project designed to answer banking-related questions using public banking documents and Large Language Models (LLMs).

## Objectives
- Understand banking-related information.
- Collect public banking documents.
- Process and organize documents.
- Integrate an LLM API.
- Generate answers to user questions.

## Technologies
- Python
- Git and GitHub
- Large Language Models (LLM)
- Natural Language Processing (NLP)

## Project Structure
- documents/ - Banking-related documents
- src/ - Python source code
- data/ - Project data

## Project Status
Currently in the initial development stage.
